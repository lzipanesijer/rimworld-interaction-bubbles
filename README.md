## Overview

Interaction Bubbles adds floating speech-bubble overlays above colonists during social interactions, letting you watch romances, arguments, and inspirations unfold in real time without pausing.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Interaction Bubbles** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Live Bubbles** | Speech overlays appear and fade with interaction timing |
| **Icon Tags** | Sentiment icons distinguish flirting, insults, and casual chat at a glance |
| **Bubble Scaling** | Configurable bubble size, duration, and opacity per player preference |
| **Mod Compatibility** | Hooks into social interaction defs added by other mods automatically |
